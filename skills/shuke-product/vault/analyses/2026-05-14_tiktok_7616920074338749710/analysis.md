### 3. 前 3 秒钩子
- **钩子类型**：**结果展示 + 痛点共鸣**。视觉上直接展示极度舒适的“碎片拼合”过程（解压感），听觉上直接抛出“对分数头疼”的痛点。
- **为什么能留住用户**：第一人称视角的实操极具代入感；数学题辅导是全球家长的共同痛点，1/4+1/4=1/2的直观动画级演示，打破了传统黑板教学的枯燥，引发了“如果我小时候有这个就好了”或“我孩子正需要这个”的好奇。
- **可优化的 3 个开头版本（针对中国区短视频/直播切片语境）**：
  1. **痛点放大版 (针对焦虑家长)**：“辅导孩子算分数，血压天天飙升？别讲干理了，看看这个！”
  2. **反常识/好奇版 (针对易错题)**：“1/4和1/3到底哪个大？别再让孩子死记硬背了，一秒钟让他看懂！”
  3. **学霸秘籍版 (针对结果导向)**：“小学数学老师不告诉你的秘密：其实分数是可以通过拼图‘玩’明白的。”

### 4. 商品与卖点
- **商品出现次数和方式**：贯穿全片100%覆盖。以“零件实操 -> 整体包装展示 -> 零件实操 -> 整体收纳展示”的逻辑交替出现。
- **明确卖点**：将分数可视化/可触摸（适合视觉学习者）、帮助辨别分数大小、磁吸设计不丢零件。
- **隐含卖点/视觉证明点**：
  - 色彩鲜艳，能吸引儿童注意力。
  - **背面信息量大**：在25秒翻转时，观众能清晰看到背面印有对应的小数（0.333/0.25）和百分比（33.3%/25%），一物三用，打通分数、小数、百分比的认知。
- **可信度证据**：全流程第一人称**实测**（真实写字、真实拼搭）、**细节**（特写镜头下的质感和印刷）、**实操防掉落**（倾斜书本验证磁吸）。

### 5. 脚本结构
- **视频采用的脚本模型**：**痛点引出 -> 场景实测证明 -> 核心误区纠正 -> 卖点补充打消顾虑 -> 软性种草**。这是一个非常经典的“教学/痛点类教具”带货模型。
- **口播核心话术**：围绕 "Struggle" (头疼/挣扎)、"Easier to see and touch" (更容易看和摸)、"Visual learner" (视觉学习者)、"Won't lose any pieces" (不会弄丢零件) 展开。
- **CTA 是否明确**：**不明确**。结尾只说 "This can really help..." (这真的能帮助...)，缺乏直接的转化指令（如“点击左下角小黄车”、“给孩子备一套”）。这更像是一条自然流种草视频，若用于投放需补强CTA。

### 6. 视觉语言
- **镜头语言**：全程采用第一人称视角（POV）俯拍，这种景别（特写至中景）极大地拉近了观众与商品的距离，仿佛观众自己正在操作。
- **色彩与光线**：光线均匀充足（类似护眼台灯光线）。白纸底色凸显了教具的高饱和度色彩（红、黄、绿、蓝等），对比强烈，视觉刺激好。
- **哪些画面最有转化价值**：
  1. **21-25秒比大小**：把1/4和1/3放在一起对比面积。这解决了一个具体的、极易犯错的教学难点，瞬间击中家长。
  2. **29-32秒倒置不掉**：证明磁吸力，解决了“买玩具最怕少零件”的隐形痛点。
- **哪些画面冗余或影响信任**：写算式的时间稍显拖沓（如0:15-0:18写1/3的过程）。在讲求快节奏的短视频平台，书写过程可以稍微加速剪辑。

### 8. 可复刻方案（适用于国内抖音/快手平台）
- **复刻脚本大纲**：
  - 0-3s：制造冲突/痛点（抛出易错题：1/4和1/3哪个大？）。
  - 4-8s：产品亮相（掏出磁力书，直接把色块摆上证明）。
  - 9-15s：进阶玩法（演示分数加法，顺便翻面展示小数和百分比的换算）。
  - 16-20s：收纳痛点（倒置书本展示磁吸，强调不掉零件）。
  - 21-25s：强势促单（强调价格优势+适用年龄+引导购物车）。
- **需要拍摄的镜头清单**：
  1. 俯拍实景：白纸上写着错误的比较大小（1/4 > 1/3，打个红叉）。
  2. 俯拍特写：手拿教具色块，放在纸上直观对比面积。
  3. 俯拍特写：翻转色块，特写背面的百分比和小数。
  4. 中景：用力甩动翻开的教具书，色块不掉落。
- **可直接使用的口播/字幕文案**：
  - “辅导小学数学，最怕孩子转不过弯！比如1/4和1/3到底哪个大？用嘴讲半天，不如用这个磁力分数本拼一下！”
  - “黄色的1/3，绿色的1/4，放在一起，大小一目了然！孩子看一眼就懂了。”
  - “不仅能算加减法，翻过来，小数、百分比全都有了，小学三到六年级的难点，一套全搞定！”
  - “全本强力磁吸，怎么甩都不掉，再也不怕丢件了。与其让孩子死记硬背，不如让他自己动手拼。左下角给孩子备一套，开学肯定用得上！”
- **改造建议**：用于投放（千川/AD）时，必须加上文案中强调的“包含小数和百分比，覆盖X年级知识点”以提升产品价值感，结尾必须有明确的手指指向左下角的动作和口播。
