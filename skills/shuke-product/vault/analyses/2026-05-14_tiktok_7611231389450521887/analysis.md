### 3. 前 3 秒钩子
- **钩子类型**：**结果展示 + 视觉解压 + 痛点代入**。
- **为什么能留住用户**：人类对“拼图完美契合”的画面有天然的停留惯性。将抽象的 $1/4 + 1/4$ 用实物完美拼成 $1/2$，产生了一种“恍然大悟”的解压感，同时一秒击中辅导数学家长的痛点。
- **可优化的 3 个开头版本（结合口播/字幕升级）**：
  1. **痛点放大版**：“还在靠切苹果教孩子分数吗？试试这个……”（画面配上切错苹果的无奈表情，转实物教具拼接）。
  2. **反差悬念版**：“为什么 1/4 加 1/4 不是 2/8？看这三秒钟你就懂了。”（动作保持不变，用易错题做钩子）。
  3. **人群精准版**：“小学三年级家长注意！搞懂分数加法，只需要这两块吸铁石。”

### 4. 商品与卖点
- **商品出现方式**：**全程穿插式**。使用场景（本子上实操）与产品全貌（包装和收纳册）交替出现。
- **明确卖点**：
  - 帮助学习分数加法和大小比较。
  - 适合视觉型学习者（Visual learner）。
  - 磁吸设计，不易丢失（Magnetized so you don't lose pieces）。
- **隐含卖点**：色彩丰富（吸引儿童注意力）、包含圆形和长条形两种认知模型、方便收纳（书本样式）。
- **视觉证明点（最强）**：
  - 1/2 的红色模块**严丝合缝**地盖住两个 1/4 的绿色模块。
  - 1/3 的黄色长条与 1/4 的绿色长条**并排放在一起**，直观看出长短差异。

### 5. 脚本结构
- **视频采用的脚本模型**：**场景实操演示 + 痛点解说模型**（类UGC评测）。
- **口播核心话术结构**：制造悬念（救命神器） -> 提出场景（我和孩子学分数） -> 原理阐述（视觉+触觉更易懂） -> 解决易错题（1/3与1/4比较） -> 强调做工（磁吸防丢）。
- **CTA (行动号召)**：**极其微弱/不明确**。视频结尾只停留在包装上，没有引导点击小黄车或购买的明确口播/字幕。

### 6. 视觉语言
- **镜头与构图**：标准的 TikTok/Reels **第一人称俯视视角（POV）**，极强代入感。镜头略带手持晃动，增加了 UGC 的真实感。
- **色彩与光线**：画面光线较暗且有手部阴影，但教具本身的高饱和度色彩（红、黄、绿、蓝）与白纸形成了强烈的视觉对比，抓人眼球。
- **最有转化价值的画面**：1/3 与 1/4 长条块并排比大小的画面。直接打破了常规认知障碍，极具说服力。
- **影响信任/冗余的画面**：
  - 全程**完全没有字幕**，在静音播放环境下信息损耗达到 80%。
  - 0:30-0:35 展示整本书页面时，镜头晃动过快，看不清其余分数块的细节。

### 8. 可复刻方案
#### 复刻脚本大纲（适合投流/自然流带货）
1. **0-3s 黄金开场**：直接拍桌子上的错题本（分数大小比较全错），家长叹气，立刻掏出教具拼搭。
2. **3-10s 核心演示**：用教具覆盖错题。演示 1/3 大于 1/4（长条对比）。
3. **10-18s 进阶演示**：演示同分母/异分母加法（拼圆盘）。
4. **18-25s 痛点补充**：“以前买的教具丢得全家都是？这个是强磁吸的，倒过来都不掉，合上就是一本书。”
5. **25-30s 逼单 CTA**：“三年级学分数必备，现在拍下只要 XX 元，左下角直接带走！”

#### 必须拍摄的镜头清单
- 特写：教具严丝合缝拼在一起的瞬间。
- 特写：两种不同分数块并列比大小的瞬间。
- 动作：把书倒过来用力晃动，证明磁吸很牢固（现频没有，建议增加）。
- 场景：孩子自己动手拼搭并露出恍然大悟表情的镜头（现频缺乏使用者反馈）。

#### 改造建议（针对原视频的直接二创优化）
如果只能剪辑原素材：必须加上**大号黄白撞色字幕**。开头配上“解决小学三年级最大痛点”的醒目标题，结尾补上“点击下方链接购买”的箭头动画。
