#### **3. 前 3 秒钩子**

*   **钩子类型：** **新闻官宣 + 身份代入 + 独家稀缺**
    *   **新闻官宣：** “Buldak is officially on TikTok” 对品牌粉丝是重要新闻。
    *   **身份代入：** 视频博主作为“发现好物者”的身份，替用户找到了官方渠道。
    *   **独家稀缺：** “TikTok shop exclusive bundle” 立即建立价值壁垒。

*   **为什么能/不能留住用户：**
    *   **能：** 对于Buldak火鸡面的认知用户或嗜辣人群，这个钩子信息密度高、价值明确，能迅速抓住他们的注意力。
    *   **不能：** 对于不了解该品牌的用户，吸引力较弱，可能因为没get到“官方入驻”的重要性而划走。

*   **可优化的 3 个开头版本：**
    1.  **结果展示钩子：** （镜头先对准一碗热气腾腾、酱汁浓郁的火鸡面）口播：“我终于找到了比我前任还辣的东西，而且只有TikTok上才有！” 然后镜头拉远，展示“Hotter Than My Ex”包装。
    2.  **场景冲突钩子：** （博主假装在普通超市货架前寻找）口播：“别再找了！火鸡面这款超酷的‘前任限定款’，只有在TikTok官方店才能买到！” 直接对比线下买不到的稀缺性。
    3.  **价格刺激钩子：** （如果价格有优势）口播：“火鸡面官方来TikTok发福利了！这个6碗装的限定款，平均一碗才XX钱，赶紧囤！” 直接用价格优势吸引用户。

*   **商品出现次数和方式：** 商品全程出现。开场是6碗组合大包装，8秒后切换为单碗展示，始终保持在画面核心位置。

    3.  **限量供应：** 库存有限，会卖断货。
    4.  **规格清晰：** 6碗装。

    1.  **社交货币：** 购买限定款产品可以在社交圈中展示和分享，满足炫耀心理。
    2.  **情绪价值：** "比我前任还火辣"的名称自带话题和幽默感，提供了情绪宣泄的出口。
    3.  **品牌力：** Buldak本身就是“辣”和“潮流”的代名词。
*   **可信度证据：**
    *   **视觉证明点：** 清晰展示了未开封的、带有官方印刷的商品包装。

#### **5. 脚本结构**

*   **视频采用的脚本模型：** **KOL开箱/新品宣发模型 (Unboxing/New Arrival Announcement)**。结构非常直接：宣布消息 -> 展示商品 -> 讲解卖点 -> 引导下单 -> 制造稀缺 -> 预告互动。
*   **口播/字幕的核心话术：**
    *   **价值前置：** "Official" (官方), "Exclusive" (独家)。
    *   **利益点：** "6 of these bowls" (6碗装)。
    *   **行动指令：** "Leave the link below" (链接在下面)。
    *   **稀缺性：** "Limited stock" (限量), "Gonna sell out" (会卖光)。
    *   **互动引导：** "Save this for later", "Come back for my tasting video"。
*   **CTA 是否明确：** **非常明确。** 博主不仅口头指引，还用手势示意了TikTok Shop链接的位置，并反复强调“看到链接就代表有货”，直接将用户的注意力引向转化按钮。

*   **光线与色彩：** 自然光，光线充足。商品包装的红色在画面中非常突出，视觉冲击力强。
*   **最有转化价值的画面：**
    1.  **0-1秒：** 整个6碗装大包装充满屏幕，视觉冲击力强，瞬间告知商品信息。
