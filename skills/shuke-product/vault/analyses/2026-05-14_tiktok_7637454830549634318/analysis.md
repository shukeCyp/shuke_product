- **商品出现次数/方式**：贯穿全片（100%覆盖）。前段作为运动道具出现，中段作为特写主角出现，后段作为暴力测评对象出现。

  - *极端实测（最有效）*：拉起两桶大桶饮用水（展现承重力）；两人极限拉伸（展现延展性和防断裂性）。

### 5. 脚本结构
- **视频采用的脚本模型**：痛点场景种草 -> 核心功能展示 -> 极限防伪测评 -> 促单转化（经典的短视频带货漏斗模型）。
- **核心话术逻辑**：如果做X动作25次 -> 就能得到Y身材结果 -> 因为我用了Z（特写） -> Z质量极好（证明） -> 马上买Z很便宜（CTA）。
- **CTA 是否明确**：非常明确。给出了具体时间期限（周末前）、价格锚点（不到10美元）、附加福利（免邮），以及情绪催促（不买会后悔）。

### 6. 视觉语言
- **构图与景别**：前段采用全景/中景展示动作标准和身材；中段迅速切入极近景（大特写）展示产品细节；测评段落运用夸张的对比构图（人与大水桶的比例）。
