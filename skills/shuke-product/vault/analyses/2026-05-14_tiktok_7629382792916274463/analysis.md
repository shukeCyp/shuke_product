### 3. 前 3 秒钩子
- **钩子类型：** **行为动作 + 视觉反差 + 结果展示预告**。两人费力抖开一个庞然大物（视觉冲击），配合“Bed Transformation”（结果预告）。
- **为什么能留住用户：** 巨大的黑色物体在视觉上具有压迫感和好奇感（这到底是什么？）；“改造”类视频自带极高的完播期待值，用户想看最终铺好的样子。
- **可优化的 3 个开头版本：**
  1. **痛点放大版：** 开头拍一个人揉着腰痛苦地从旧床垫上醒来，随后快切到商品重砸在床上的画面（配字幕：腰痛人的救星！）。
  2. **价格刺激版：** 开头直接手举几张钞票丢在旧床上，字幕：“如何用XX块钱，把出租屋的硬床变成五星级套房？”
  3. **极致暴力测试版：** 开头从高处往这个床褥上扔一个生鸡蛋或者保龄球，展示极致的缓冲效果。

### 4. 商品与卖点
- **商品出现次数/方式：** 全程贯穿。从折叠状态 -> 铺装过程 -> 整体展示 -> 细节特写。
- **明确卖点：** 竹纤维凉感（Bamboo cooling）、全网最厚（Thickest）、大促销（Massive sale）。
- **隐含卖点：** 像床笠一样自带一圈包边（侧面特写时展示，暗示防滑易固定）、百搭颜值（深灰色耐脏且高级）。
- **视觉证明点（Evidence）：**
  - **实测证明：** 真人全身扑倒、在床上跳跃（证明缓冲和弹性）。
  - **细节证明：** 手部深度按压特写（直观感受厚度和填充物饱满度）、侧视图展示厚度。
  - **第三方背书：** 对话形式的 UGC 测评，利用室友/情侣的惊讶反应作为社交证明。

### 5. 脚本结构
- **采用的模型：场景种草 + 提问解答反转（Q&A / Objection Handling）**。
  - 抛出产品 -> 提出疑问（是凉感的吗？） -> 解答并强化卖点（不仅是，还是最厚的） -> 体验震撼（像新床垫） -> 提出顾虑（肯定很贵） -> 大促反转逼单（骨折价）。
- **核心话术：** “Feels like a new mattress”（感觉像新床垫）——这句话是全片文案的灵魂，完美传达了商品的价值上限。
- **CTA（行动呼吁）是否明确：** **不明确**。视频结尾只提到了大促，但缺少指示性动作（如“点击左下角小黄车”、“主页链接查看”等），导致转化路径在此处断掉。
