### 3. 前 3 秒钩子
- **钩子类型**：**价格刺激 + 身份共鸣**。字幕直接点出“认为它很贵”，利用价格反差预期留住用户。
- **为什么能留住用户**：很多人不买户外储物箱是因为觉得大件家具贵，文案直接否定了这一点，引发好奇（“那到底多便宜？”）；同时画面开始装入巨大的儿童玩具，动态画面避免了开场枯燥。
- **可优化的 3 个开头版本**：
  1. **痛点对比钩子**：前1秒满院子乱七八糟的玩具（带“宝妈抓狂”音效），第2秒一扫而空全装进箱子。（视觉冲击更强）
  2. **暴力测试前置钩子**：第1秒直接播放水管狂喷储物箱的画面，配文：“放院子里天天暴晒淋雨？打开一看我惊了！”（猎奇+悬念）
  3. **极致容量钩子**：画面是一座“玩具山”和空箱子，配文：“挑战把这堆‘垃圾’塞进这个箱子，结果还能装下俩娃？”

### 4. 商品与卖点
- **商品出现次数和方式**：贯穿全片 100% 出现。从空箱 -> 填满 -> 淋水 -> 细节 -> 关箱，全方位无死角展示。
- **明确卖点**：超大容量、防水、防晒（抗UV）、预留锁孔、性价比高。
- **隐含卖点**：仿藤编纹理（颜值高、融入庭院环境）、材质轻便（单手可开合）、安装拼接口严密（不漏水）。
- **视觉证明点/可信度证据**：
  - **实测证明**：水管直接喷淋 + 内部干燥特写（最强有力的信任背书）。
  - **参照物证明**：用大家熟悉的儿童推车、棒球棍作为参照物，比单纯报尺寸数字直观100倍。
  - **细节证明**：给锁孔特写、给箱体表面的水珠特写（展示材质的拒水性）。

### 8. 可复刻方案

**复刻脚本大纲（适用于同类收纳/家居防尘防水产品）：**
1. **0-3s 痛点反差**：展示满地杂物 -> 一秒清空入箱。抛出低价或平替概念。
2. **3-8s 极限塞物**：快进播放装入各种大件/奇葩形状物品的过程，强调“无底洞”容量。
3. **8-15s 暴力破坏**：泼水/撒土/踩踏（视产品而定），随后打开展示内部安然无恙。
4. **15-20s 细节+逼单**：展示五金/材质/锁扣等细节，点出适用人群，引导小黄车。
