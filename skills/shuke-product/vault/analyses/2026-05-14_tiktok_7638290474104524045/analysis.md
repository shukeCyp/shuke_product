### 2. 时间轴拆解

*   **0-3s：痛点共鸣与结果展示**
    *   **画面内容：** 一名戴鸭舌帽的男子穿着亮橙色长袖，站在阳光下的车道上，面向镜头充满活力地讲话。

*   **3-8s：个人背书与舒适度强调**
    *   **画面/动作：** 人物轻抚胸前的布料，表情夸张地强调舒适度。
    *   **字幕/口播：** "...and I have seriously never been more comfortable in the sun in my life. These things are nice." (说真的，我这辈子在太阳底下从来没这么舒服过。这衣服真不错。)

*   **8-15s：核心卖点输出（防晒+轻薄）**
    *   **画面/动作：** 镜头通过跳剪（Jump Cut），人物身上的衣服瞬间从橙色变成白色。人物弯腰靠近镜头，拉扯衣服下摆。

*   **15-22s：视觉证明点（弹力+版型）**
    *   **画面/动作：** 双手向外拉扯衣服腹部的面料，展示极佳的延展性，然后衣服迅速回弹贴合身体。

*   **22-26s：进阶卖点（凉感/吸汗）**
    *   **画面/动作：** 再次拉近镜头，配合手部动作强调。
    *   **字幕/口播：** "And they're moisture-wicking, so if you start sweating at all, you get even cooler." (而且它们吸湿排汗，所以如果你开始出汗，你会感觉更凉快。)

### 4. 商品与卖点
*   **商品出现次数和方式：** 全程出现 (100%占比)。通过主播真人试穿、跳剪换色来展示。
*   **明确卖点：** UPF 50+防晒、阻挡UVA/UVB、轻薄透气、高弹力、吸湿排汗、多色可选、夏日打折。
*   **隐含卖点：** 穿着显瘦/版型好（主播穿上不显臃肿）、适合日常及户外场景。
*   **可信度证据：**

### 5. 脚本结构
*   **视频采用的脚本模型：** 痛点-解决 (PAS) + 场景种草。
    *   提出问题/引入方案 -> 阐述核心科技（防晒/轻薄） -> 物理展示（弹力） -> 升华体验（出汗更凉） -> 促销促单。
*   **核心话术设计：** 典型的“兄弟推荐”口吻 (Bro-marketing)。语言通俗，不用过于专业的服装术语，而是用 "never been more comfortable", "beat the heat" 这种情绪化表达。
*   **CTA 是否明确：** 非常明确。在视频最后 3 秒直接说出 "link right here" 并配合手势指向屏幕下方的购物车位置。

### 6. 视觉语言
*   **构图/景别：** 竖屏 9:16 满屏人物构图。以近景（胸部以上）和中景（腰部以上）为主，随着主播的讲述，身体会有前倾靠近镜头的压迫感，增强对话感。

### 8. 可复刻方案

**复刻脚本大纲：**
1. **0-3s 钩子**：抛出痛点+穿着展示（找对衣服了）。
2. **4-10s 痛点转折**：陈述普通长袖的缺点，引出本款UPF50+核心卖点。
3. **11-18s 视觉实测**：拉扯弹力 + 滴水展示（原版没有，复刻必加）。
4. **19-25s 场景延伸**：说明适合出汗场景，强调越出汗越凉快。
5. **26-30s 逼单**：换色跳剪 + 强调打折 + 手指下方。

1. A-roll: 主播在阳光下情绪饱满的口播（中景）。
2. A-roll: 跳剪换不同颜色的同款衣服。
3. B-roll (特写): 双手用力拉扯衣服面料展示弹力。
4. B-roll (特写-需补充): 用喷壶在衣服上喷水，展示水滴迅速扩散吸收（吸湿排汗）。
