### 3. 前 3 秒钩子
- **钩子类型**：**身份代入（Identity）+ 结果假设（Curiosity）**。文字“Short kings”直接精准定向特定人群；口播“如果我吃了它能长到2米1”用夸张的预期结果制造好奇。
- **为什么能/不能留住用户**：
  - **能**：语速极快，情绪饱满，文字标签精准过滤了无关人群，留下的都是有痛点的精准用户。
  - **不能**：画面较为粗糙，室内顶光显得不够专业；直接拿着药瓶可能让对广告极度排斥的用户瞬间划走。
- **可优化的 3 个开头版本**：
  1. **痛点前置型**：“别再叫我‘矮个子’了！如果你还没满25岁，这可能是你最后的机会...”
  2. **视觉反差型**：（手里拿着一把卷尺拉开）“想突破你的基因极限吗？25岁前骨骺线闭合前的秘密武器是这个...”
  3. **情绪共鸣型**：“还在因为身高被拒绝吗？我原本也以为身高只能靠天生，直到我发现了这个...”

### 4. 商品与卖点
- **商品出现次数和出现方式**：商品在100%的视频时间里出现。全程由博主单手举在脸部附近展示。
- **明确卖点**：最大化促进身高增长（Height maximizer）、提供生长助力、适合25岁以下。
- **隐含卖点**：安全（博主声称会给自家孩子吃）、有效（号称上一批卖空了）。
- **视觉证明点**：**极弱**。仅展示了药瓶外观，未展示胶囊颗粒，未展示前后对比图，未展示成分表。
- **可信度证据**：严重缺乏**客观**证据。口播提到了“大量研究支持（backed by research）”，但没有出示任何文献截图、第三方检测报告或真实的买家秀。唯一的“背书”是博主极度自信的表达和个人的口头保证。

### 5. 脚本结构
- **视频采用的脚本模型**：**痛点-解决-逼单模型 (PAS: Problem - Agitation - Solution)**。
  提出痛点（长不高） -> 放大痛点（展示矮星人照片） -> 提出解决方案（展示补剂） -> 制造稀缺与门槛（25岁死线、经常断货） -> 明确指令（点击购买）。
- **口播的核心话术逻辑**：使用大量绝对化和极具情绪煽动性的词汇，如“easy work（轻轻松松）”、“maximum boost（最大助力）”、“you're cooked（你没戏了/完蛋了）”、“sold out（售罄）”。
- **CTA 是否明确**：**非常明确**。视频最后10秒连续两次口头要求“Check the link down below”并配合手部向下指的动作。

### 6. 视觉语言
- **构图/景别**：竖屏居中构图，面部特写/中近景为主，典型的TikTok/Reels原生UGC风格，拉近与观众的心理距离。
- **镜头/运镜**：固定机位（手持自拍），没有复杂的运镜，全靠博主的肢体语言和表情变化。
- **剪辑节奏**：一镜到底或无缝跳剪，节奏紧凑，没有废话和停顿。
- **画中画设计**：3-8秒出现的“小恶魔”照片是一个绝佳的**视觉干扰（Pattern Interrupt）**，有效防止用户视觉疲劳，同时直击痛点。
- **哪些画面最有转化价值**：指着下方链接并强调“上一批卖断货”时的急迫表情和手势，转化引导力最强。
- **哪些画面冗余或影响信任**：全程没有展示产品内部形态。对于入口的营养补充剂，不展示药片/胶囊的大小和颜色，会大幅降低购买信任感。
