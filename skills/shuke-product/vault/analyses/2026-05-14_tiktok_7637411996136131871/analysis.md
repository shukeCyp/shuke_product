### 3. 前 3 秒钩子
- **钩子类型**：**痛点前置 + 制造悬念 + 极端场景冲突**（"Before you die" 极具视觉和听觉冲击力）。
- **为什么能留住用户**：
  1. 话题足够沉重且不可避免，触发了人类本能的“损失厌恶”。
  2. “3件事”的清晰结构降低了认知门槛，让人本能地想看完到底是哪三件事。
  3. 笔尖指引的POV视角代入感极强，像是在上私教课。
- **可优化的 3 个开头版本（假设做测试）**：
  - *版本A（算账刺激型）*：“你知道如果你意外离世，政府会从你的房产里抽走多少钱吗？翻开第X页…”

### 4. 商品与卖点
- **商品出现次数和方式**：贯穿全片 100%。产品即画面主体，采用翻阅、指读的沉浸式展示。
- **明确卖点**：手把手教你建立生前信托；包含所需的所有表格；保护财富不被缩水。
- **隐含卖点**：通俗易懂（排版字大、列表清晰）；权威专业（厚厚一本，目录详尽）。
- **视觉证明点**：真实的翻页哗啦声、密密麻麻的专业目录、封底的“解锁终极指南”等字眼。
- **可信度证据**：**实体展示 + 内容实拍**。没有虚构夸大的特效，纯靠展示书本内的真实文字来获取信任。

### 5. 脚本结构
- **视频采用的脚本模型**：**清单体干货 + 痛点恐吓 + 解决方案引导（Listicle -> Agitation -> CTA）**。
- **核心话术拆解**：
  - *抛出诱饵*：教你3个高价值干货。
  - *制造危机*：“别做任人宰割的羔羊” / “财富可能彻底丧失”。
  - *提供解药*：“所有的表格和步骤都在这本蓝图里”。
  - *催促行动*：“趁链接还在赶紧买，别让系统拿走你的钱”。
- **CTA 是否明确**：**极其明确**。直接点名了平台的转化组件（"orange card" 指 TikTok Shop 典型的橙色购物链接），使用了祈使句（Tap it, grab it）。

### 8. 可复刻方案（以国内卖《财产传承规划》类书籍为例）

- **复刻脚本大纲**：
  1. 笔尖指着书本大标题：“突发意外前，必须为家人做的3个兜底安排”。

  3. 快速翻阅目录，展示干货密度，画外音提示不做的严重后果（如争产打官司）。
  4. 翻到封底，对齐卖点，引导左下角小黄车。
- **镜头清单**：
  - 镜头1（0-10s）：书本正文特写，手持马克笔划重点。
  - 镜头2（10-15s）：从下往上快速翻动书页，露出密集的目录标题。
  - 镜头3（15-20s）：书本封底特写，笔尖敲击核心卖点文字。
