*   **商品出现次数和方式**：全程出镜（11秒），从单品特写 -> 佩戴上头 -> 静态展示 -> 动态甩动 -> 多种造型展示，完成了360度的商品教育。

### 8. 可复刻方案

*   **复刻脚本大纲**：
    1.  **0-2s 痛点+操作**：展示稀疏真发，直接扣上假发片。（字幕：发量少？3秒搞定）
    2.  **2-5s 惊艳反转**：拨开假发，展示背影瀑布发。手指穿过头发梳理。（字幕：自然无痕，发量翻倍）
    3.  **5-8s 细节实测**：用力拉扯几下证明牢固，梳子梳理证明顺滑不打结。（字幕：牢固不掉，哑光高温丝）
    4.  **8-12s 造型+CTA**：扎马尾或戴发夹，手指指向屏幕下方。（字幕：一杯奶茶钱，多种造型随意换，左下角带走）

*   **需要拍摄的镜头清单**：
    1.  假发片内网/卡扣的特写镜头。
    2.  佩戴前，头顶扁塌的侧面/背面特写。
    3.  佩戴瞬间的连贯动作（中景）。
    4.  手指穿过假发顺到底的镜头（证明不打结）。
    5.  用手拉扯发根的镜头（证明牢固）。

*   **适合投放/自然流/直播切片的改造建议**：
    *   **如果是自然流**：保持现在的纯音乐节奏，但必须在视频上方/下方添加**大字报字幕**（如：“免染发直接拥有微醺酒红卷”），在评论区置顶购买链接。
    *   **如果是千川/信息流投放**：必须加入真人配音，前3秒提炼痛点，中后段强调**价格（例如“不到去理发店十分之一的价格”）**，结尾加入明确的“左下角小黄车下单”手势或动画。
