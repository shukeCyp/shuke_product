### 2. 时间轴拆解

*   **0-3s：抛出疑问与锚定价格**
    *   **画面内容**：博主坐在车内驾驶座，手持ALT香水。画面中央有显眼的白底黑字贴纸“Does it really smell like Creed?”（真的闻起来像Creed吗？）。画面上方叠加了原版Creed香水的图片及被划掉的“$510.00”高价标签。

    *   **转化作用**：利用大牌知名度和极高的价格锚点（510美元）制造强烈反差，利用核心疑问瞬间抓住对香水感兴趣或想省钱的受众。
*   **3-15s：商品引出与痛点共鸣**
    *   **画面内容**：博主将ALT香水瓶怼近镜头特写展示，随后拿回胸前。
    *   **动作/口播**：指出该产品灵感来自全球最受欢迎的古龙水，但专为“没有500美元买香水，或不想花那么多钱买香水的人”设计。
    *   **转化作用**：明确产品定位（平替），并与目标用户的消费痛点（嫌贵/没钱）产生强烈的情绪共鸣，合理化购买行为。
*   **15-30s：信任背书与结果承诺**
    *   **画面内容**：保持车内单机位口播，博主配合手势强调。
    *   **动作/口播**：强调“味道完全一样，价格便宜得多”。并给出强力断言：“99.9%的人闻不出它（ALT）和这个（指着原版贴纸）的区别”。博主加入亲身经历：“我戴着它，有人问我是不是喷了那个（Creed）。”
    *   **转化作用**：通过主观断言（99.9%）和个人真实故事背书（被人误认），打消用户对“平替=劣质”的顾虑，建立产品信任感。
*   **30s+：逻辑闭环与行为召唤 (CTA)**
    *   **画面内容**：博主身体前倾，态度变得更加诚恳。
    *   **动作/口播**：发起灵魂拷问：“问问你自己，既然能用少得多的钱买到完全一样的味道，为什么要花500美元？” 最后明确指向：“在你花500美元之前，帮自己个忙，买这个，我把链接放在下面。”
    *   **转化作用**：最后一次强化价格对比，提供直接的行动指令（买这个、点击下方链接），促成冲动下单。

### 5. 脚本结构
*   **采用的脚本模型**：典型的 **“痛点-解决” 与 “大牌平替 (Dupe) 推荐”** 模型。
    *   提问引出大牌 -> 抛出原版高价痛点 -> 拿出平替方案 -> 个人体验背书证明 -> 算账逼单闭环 -> CTA引导。
*   **核心话术**：“exact same smell”（完全一样的味道）、“cost way less”（花费少得多）、“99.9% can't tell the difference”（99.9%的人分不清）。
*   **CTA是否明确**：非常明确。口播“grab this instead”（买这个替代），并配合手指指向屏幕下方（小黄车/链接位置），话术是“I'll link it down below”。

### 6. 视觉语言
*   **构图/景别**：车内中近景（胸部以上），竖屏构图。人物居中，商品在画面左下方，贴纸在人物头部上方，形成视觉三角，构图极佳。
