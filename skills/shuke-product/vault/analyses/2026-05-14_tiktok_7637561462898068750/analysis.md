### 4. 商品与卖点
- **商品出现次数和出现方式**：商品在 0-3s 揭秘后，全程在画面的绝对中心（C位），以车载实机演示和手持特写两种方式呈现。
- **明确卖点**：红外星空顶投影（可调模式）、自带苹果/安卓双伸缩线、比初代更便宜。
- **隐含卖点**：数字电压监测（屏幕显示 14.6 等数字）、多口扩展（除了伸缩线，还有额外的USB-A和Type-C接口，支持多人同时充）、体积小巧不占空间。
- **可信度证据**：
  - **实测证明**：特意将镜头摇向天窗，证明星星是投影而非贴纸或真星空顶改装。

### 5. 脚本结构
- **视频采用的脚本模型**：**场景种草 + 核心功能展示 + 价格/稀缺性逼单** (Hook -> Value -> Offer -> CTA)。
- **核心话术拆解**：
  1. **引入**：This upgraded car charger is crazy... (这个升级版车充太疯狂了)
  2. **证明**：I don't have any actual stars... it's all coming from this little laser. (车顶没改装，全靠这个小激光)
  3. **功能**：Still has both retractable cables... (依然自带双伸缩线)
  4. **价格**：Literally cheaper than the first one. (比第一代还便宜)
  5. **逼单**：Selling out really fast... link right here. (快卖光了，链接在这)
- **CTA 是否明确**：极其明确。口播配合手部动作，直接指向屏幕右下角（TikTok/抖音常见的购物车位置）。

### 6. 视觉语言
- **构图与景别**：全程竖屏满屏构图，以第一人称主观视角（POV）为主。大量使用微距特写（Macro/Close-up），将原本体积较小的车充放大到填满屏幕中下部。
- **运镜与剪辑节奏**：一镜到底（或隐藏剪辑的高级伪一镜到底），镜头跟随手部动作游走，节奏紧凑，没有多余的空镜头。
- **光线与色彩**：典型的赛博朋克/暗黑电竞风。环境极暗，完全靠设备自带的蓝光LED面板和红色的激光投影作为主要光源，极大地凸显了产品的“科技感”和“氛围感”。
- **最有转化价值的画面**：
  1. **0:14 抽出两条充电线**：直观展示核心痛点解决方案，动作丝滑。
  2. **0:01 满天星车顶**：极强的种草视觉。
- **影响信任的画面**：设备面板上的字体排版极其密集，且由于LED蓝光溢出（眩光），导致某些标识看不清，略显廉价感/塑料感。
