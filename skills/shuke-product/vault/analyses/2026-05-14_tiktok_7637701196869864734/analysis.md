### 3. 前 3 秒钩子

- **为什么能留住用户**：极具真实感（UGC原生感）。没有精美的片头，就像是朋友圈里的大姐在跟你视频通话分享刚买到的好东西，这种不修边幅的真实感在满是精美广告的信息流中反而能建立初始信任。

### 4. 商品与卖点
- **商品出现次数和出现方式**：商品贯穿全片，以纯自然状态（折叠状）握在博主手中。
- **明确卖点**：100%纯棉 (100% algodón)；极其清凉/透气 (súper frescas)；便宜且质量好。
- **隐含卖点**：纯白色百搭、易折叠收纳。
- **视觉证明点**：博主揉捏面料时的褶皱感、床单边缘的缝边工艺。
- **可信度证据**：主要依赖**真实场景背书**（真实的居家背景：吊扇、旧相框）和**博主的情绪背书**（强烈的喜爱之情）。缺乏实测（如倒水测试透气性）和场景（铺在床上的样子）。

### 8. 可复刻方案（优化后）
- **复刻脚本大纲**：开箱悬念 -> 触感夸张表达 -> **补充核心动作：展开铺床/细节展示** -> 痛点结合卖点 -> CTA。

  1. 中景：博主激动拆快递。
  2. 近景：双手揉搓面料，展示无滤镜质感。
  3. **补充空镜（B-roll）**：将纯白床单猛地扬起铺在床上的慢动作镜头（体现轻盈、平整）。
  4. 特写：在床单上放一个重物（如手机），展示没有多余褶皱；或用手抚摸平整的床铺。
