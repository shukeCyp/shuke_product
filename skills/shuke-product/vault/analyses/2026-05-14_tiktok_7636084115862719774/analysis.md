### 3. 前 3 秒钩子
*   **钩子类型**：**结果展示 + 视觉反差**。画面是一杯看似普通甚至像是不健康的街头果汁（结果展示），但屏幕中央赫然打出极度健康的成分表“20g蛋白、0糖、100大卡”（视觉反差）。
*   **为什么能留住用户**：第一，冰块碰撞的声音和清爽的黄色液体在视觉和听觉上具有“解渴”的本能吸引力（ASMR效应）；第二，打破常识（果汁外表+蛋白粉内核），引发用户好奇“这是什么神仙饮料？”。
*   **可优化的 3 个开头版本（如果投放遇颈）**：
    1.  **痛点前置型**：前1秒女主一脸痛苦地喝一口浓稠的传统巧克力蛋白奶昔并推开，第2秒切到她开心地喝这杯透明果汁。（强化对比）
    2.  **制造悬念型**：画面依然是搅动这杯果汁，加上配音：“打赌你猜不到这杯‘奶茶店果汁’里有20克蛋白质且0糖。”
    3.  **身份代入型**：配音“如果你和我一样，喝不下任何粘稠的蛋白粉，那这个绝对是你的救星。”配合倾倒冰块果汁的画面。

### 4. 商品与卖点
*   **商品出现次数和方式**：
    *   成品状态（杯装饮料）：多次贯穿全片（开头、中间、结尾）。
    *   包装袋展现：2次（室内展示主推款，室外展示两个新口味）。
    *   粉末状态：1次（特写勺子舀粉）。
*   **明确卖点**：芒果菠萝味（及另外两款）、20g蛋白质、6g膳食纤维、100大卡、含电解质和益生元、0糖。现在有折扣（On sale）。
*   **隐含卖点**：易溶解（摇摇杯随便一摇倒出来没有结块）、百搭好喝、颜值高（适合拍照发社交媒体）、适合夏日解暑。
*   **视觉证明点**：
    *   **清澈度证明**：倒进透明杯子的瞬间，液体不浑浊。
    *   **非粘稠证明**：水流的形态是清脆的液体，没有挂壁的糊状物。

### 5. 脚本结构
*   **视频采用的脚本模型**：**原生种草（UGC）+ 痛点/解决模型**。
    *   展示诱人成品 -> 抛出传统痛点（粘稠难喝） -> 给出解决方案（本产品清爽好喝） -> 证明操作简单 -> 抛出促销利益点收单。
*   **核心话术设计**：
    *   *类比法*：“Tastes like a drive-thru” （借用已知的好味道来降低尝试门槛）。
    *   *拉踩法*：“not heavy and chalky” （精准打击竞品痛点）。
    *   *人群标签*：“perfect girly drink” （引发圈层共鸣）。
*   **CTA 是否明确**：非常明确。在视频最后几秒搭配极具食欲的倒果汁画面，明确说出“现在打折（on sale right now），链接在下方（linked below）”。

**复刻脚本大纲（25-30秒紧凑版）：**

3.  **8-15s 实操证明**：展示包装 -> 舀出一勺粉 -> 倒水摇晃。“只要加水一摇，竟然是清透的果汁口感！”

5.  **20-25s 逼单**：再次展示挂着水珠的冰杯特写。“今天直播间/左下角有惊喜破价，手慢无！”

**需要拍摄的镜头清单：**
1.  怼脸/半身：喝饮料享受的反应（自然光，背景干净）。
2.  特写：装满冰块的透明玻璃杯（杯壁要有冷凝水珠）。
3.  特写：将摇好的液体倾倒在冰块上（需要慢动作/高帧率拍摄，捕捉水流和冰块）。
4.  特写：产品的包装正面（必须清晰无反光）。
5.  动作特写：用勺子从袋子里舀出粉末的瞬间。
6.  环境特写：在阳光明媚的户外手持产品包装。
