### 3. 前 3 秒钩子
- **钩子类型**：**灵魂发问（痛点）** + **视觉动势（抛掷）** + **身份代入（有娃家庭）**。
- **为什么能留住用户**：
  1. 动势开场：第一帧一块巨大的布飞过屏幕，打破静态，人类本能会追随运动物体。
  2. 极强的人群定向：第一句台词直接锁定“If you have kids”，过滤非目标群体，提高完播粉丝精准度。
  3. 色彩反差：深棕色垫子与米白色沙发形成强烈的视觉对比。
- **可优化的 3 个开头版本（针对不同人群）**：
  1. **测评反差向**：倒一杯水或撒一把零食在沙发垫上，一秒抖落/擦干。（强化易清洁）
  2. **痛点放大向**：先展示一个被猫抓烂或被孩子画花的沙发特写，然后一个响指瞬间盖上漂亮的沙发垫。（强化“遮瑕”卖点）
  3. **细节悬念向**：开局极度特写背面密密麻麻的防滑颗粒，字幕：“为什么我的沙发垫熊孩子怎么蹦都不掉？”（强化防滑卖点）

### 4. 商品与卖点
- **商品出现次数和方式**：贯穿全片（动态抛掷 -> 铺设过程 -> 局部特写 -> 全景效果）。
- **明确卖点**：可机洗 (Machine washable)、防滑 (non-slip)、防抓挠 (scratch resistant)、保护沙发/遮瑕。
- **隐含卖点**：安装极简（一人轻松搞定，无需绑带）、颜值高（波浪形裙边、复古刺绣）、触感柔软（法兰绒质感）。
- **可信度证据**：
  - *视觉证明*：翻开底面展示密集的滴塑防滑颗粒（证实防滑）；手指划过绒面（证实柔软）。
  - *场景证明*：铺完后与现代家居环境高度融合，毫无违和感。
  - *缺失的证据*（可优化）：口播提到了“防抓挠”，但画面没有配合钥匙划或剪刀刮的动作，缺乏实证。

### 5. 脚本结构
- **视频采用的脚本模型**：**痛点共鸣 -> 极简痛点解决（铺装） -> 核心卖点罗列（特写） -> 场景种草（全景）**。
- **核心话术拆解**：
  - *共鸣*：你的沙发不干净，是孩子的蹦床。
  - *方案*：我铺了这个沙发垫。
  - *利益*：机洗、防滑、防抓。保护新沙发或拯救烂沙发。
- **CTA 是否明确**：非常明确。“I linked it down below”（我在下面放了链接），配合字幕指示用户下单。

- **复刻脚本大纲**：
