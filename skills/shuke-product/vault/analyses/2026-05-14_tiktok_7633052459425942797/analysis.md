### 3. 前 3 秒钩子
- **钩子类型**：**动作展示 + 结果导向**（属于“直接切入正题”的开箱演示类）。
- **为什么能留住用户**：没有废话，第一秒就展现了机器运作的机械感和果汁流出的画面，利用了人类对“动态机械运作”的自然关注。
- **可优化的 3 个开头版本（针对投放或自然流提穿透率）**：
  1. **痛点反差型**：前1秒展现双手使劲挤橙子挤不出多少汁的痛苦表情，第2秒切入机器轻松旋转的画面。口播：“还在用手挤果汁吗？”
  2. **结果悬念型**：视频第一帧直接贴脸展示那个被完全“掏空”的干净果皮，口播：“猜猜我是怎么一滴不漏把它掏空的？”
  3. **ASMR暴力爽感型**：直接放大第0:29秒果汁如瀑布般流入玻璃罐的特写镜头，配上清脆的冰块声或水流声，停留2秒后再开始演示榨汁过程。

### 5. 脚本结构
- **视频采用的脚本模型**：**测评-证明模型（Show, don't tell）**。这是一种典型的海外UGC/种草视频结构：动作演示 -> 展示震撼结果 -> 强化爽感 -> 试用/试吃 -> 引导下单。
- **核心话术**：
  - 证明类：“看看这中间（被掏空）”、“哇，里面什么都没剩！”
  - 爽感类：“这是我最喜欢的部分，看看这倒出来的感觉！”
  - 行动类：“如果你想在夏天拥有一款好的榨汁机...链接在下面。”
- **CTA 是否明确**：非常明确。在视频最后10秒，不仅有口头引导“去买吧”，还有明确的手势动作（手指下方）配合。

### 8. 可复刻方案（适用于自然流带货）

**复刻脚本大纲**：
1. **钩子 (0-3s)**：展示被掏空的半个橙子皮贴脸特写。“不留一滴果汁，它是怎么做到的？”
2. **演示 (3-8s)**：机器特写，一键按下，看着机器旋转剥离果肉。
3. **验货 (8-15s)**：拿出果皮展示对比（最好配上惊讶的表情）。
4. **爽感 (15-25s)**：连续榨多个水果，打开阀门，果汁流入装满冰块的玻璃杯（增加冰块能提升夏日转化率）。
5. **CTA (25-35s)**：端起杯子喝一口，给出极高评价，指引左下角小黄车。

**需要拍摄的镜头清单**：
- [ ] 机器运作的主观视角特写（能看到果肉被分离）。
- [ ] 挤压前后，饱满水果与干瘪果皮的对比特写。
- [ ] 满仓果汁流向透明玻璃杯的侧面特写（重点抓拍流动感）。
- [ ] 人物在明亮厨房饮用果汁的满足表情。
